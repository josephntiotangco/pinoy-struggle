## Gloria’s moves

Choose **Gloria** on the Mode Select page before entering Arena or Survival. Her skills are available to try on the same page.

| Key | Move | Effect |
| --- | --- | --- |
| `J` | Slap | Close-range strike that builds Special on hit |
| `K` | Throw | Throws a stapler that builds Special on hit |
| `L` | Basooka | Fires a beam straight ahead for one Special Bar |
| `I` | Kick Barrage | Lands three rapid kicks for one Special Bar |
| `O` | Spirit Bomb | Requires two full Special Bars and empties the meter for a one-hit knockout |

Spirit Bomb takes 2.7 seconds to charge overhead before Gloria calls out and releases it downward. It protects her through landing and knocks out the Arena opponent from anywhere or clears all active enemies in Survival. Hold `U` to Pray in Arena or collect Charge Tokens to build Special in Survival.

## Survival controls

Use `W A S D` or the arrow keys to move around the arena. Press `J` to punch, `K` to kick, `L` for Kamehame Haduken, `I` for the Konoha Senpu area attack, and `Esc` to pause. On a phone, use the touch controls.

Pick up cross-shaped **Charge Tokens** to fill one Special Bar each. Land punches and kicks to earn more charge. Juan starts each new arena at full health and keeps his Special charge.

<!-- JT-2026/11/24 - explain when the survival blast knocks out enemies across the arena -->
With at least two full Special Bars, press **`O`** or tap **Almighty Push**. The cast empties the meter and knocks out every enemy already on the field as Juan says “Push!”

## Host on Vercel

1. Push this project folder to a GitHub repository.
2. In Vercel, create a **New Project** and import the repository.
3. Keep the root directory set to the folder containing `index.html` and `vercel.json`. Use **Other** as the framework preset.
4. Click **Deploy**. The included [vercel.json](vercel.json) serves the game files directly. Open the URL Vercel provides to play online.

[Vercel's Git deployment guide](https://vercel.com/docs/git)

<!-- JT-2026/11/26 - document the web leaderboard and its first deployment -->
### Web leaderboard

Enter a nickname to join the public leaderboard. Arena ranks levels cleared, and Survival ranks waves cleared across the full run. Faster active play time breaks ties. The site keeps each player's best result per mode in the same browser profile.

1. Connect a Neon database to the Vercel project and confirm `DATABASE_URL` is available in Production.
2. In the Neon SQL Editor, run [database/leaderboard.sql](database/leaderboard.sql) on the branch connected to Production. This creates the tables.
3. Deploy the updated web project. Open the site, enter a nickname, clear the first level or wave, and check the corresponding leaderboard tab.

The Android app uses its own menus and runs offline. The web game can be played unranked when the leaderboard service is unavailable.
